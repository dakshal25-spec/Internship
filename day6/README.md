# Day 6: File Handling

This folder contains a Python program that reads a text file, generates a summary report, and logs the activity.

## How to run the program:
1. Open your terminal.
2. Navigate to the `day6-file-handling` folder.
3. Run the program: `python file_processor.py`
4. When prompted, enter `sample.txt` or the name of any other text file in the folder.
